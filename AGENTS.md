# Consignes pour Codex

Ce fichier rassemble les conventions de travail propres au dépôt Corsa Alta. Il s’applique à tout le dépôt.

## Travailler dans ce dépôt

- Avant une modification, lire les fichiers concernés et préserver les changements locaux de l’utilisateur.
- Limiter les modifications à la demande et suivre les conventions déjà présentes dans le code.
- Après une modification, exécuter les vérifications pertinentes disponibles et signaler celles qui n’ont pas pu être effectuées.

## Processus de développement

Le projet suit les pratiques de développement logiciel utilisées en entreprise. Adapter le niveau de formalisation à l’impact du changement.

- Pour une évolution fonctionnelle, documenter le besoin et ses critères d’acceptation. Tenir à jour les exigences identifiées et vérifiables dans [GAME_DESIGN.md](GAME_DESIGN.md).
- Consigner les décisions techniques structurantes et leur justification. Relier, lorsqu’ils existent, le ticket, les exigences, la pull request et les vérifications correspondantes.
- Préparer des changements faciles à relire. Appuyer la revue de code sur des vérifications reproductibles et les automatiser dans l’intégration continue lorsque le projet le permet.
- Pour une version distribuée, identifier la version et documenter les changements utiles au joueur.

## Mettre à jour ces consignes

- Ajouter les conventions durables convenues avec l’utilisateur et les commandes de développement vérifiées au fur et à mesure qu’elles sont établies.
- Corriger les consignes devenues obsolètes. Garder les notes temporaires et les secrets hors de ce fichier.
